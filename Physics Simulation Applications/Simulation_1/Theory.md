# Math Rendering Test

## Hamiltonian

```math
H = 4E_C(\hat n-n_g)^2 - E_J\cos(\hat\phi)
```

## Eigenvalue Equation

```math
H|j\rangle = E_j|j\rangle
```

## Transition Frequency

```math
f_{01} = \frac{E_1-E_0}{h}
```

## Population

```math
P_j(t)=\langle j|\rho(t)|j\rangle
```

## Lindblad Equation

```math
\frac{d\rho}{dt}
=
-\frac{i}{\hbar}[H,\rho]
+
L\rho L^\dagger
-
\frac{1}{2}
\{L^\dagger L,\rho\}
```

## Neural Operator

```math
\mathcal{G}:u(t)\longrightarrow\mathbf{P}(t)
```
